Janak & Rajni Baby Shower — final local test folder

1. Extract the ZIP.
2. Copy your own song to this folder and rename it music.mp3.
3. Open index.html in Chrome or Edge.
4. Tap the envelope to open the invitation and start music.
5. Check Ganesh Vandana at the top and Sanskrit blessing in place of date/time on the cover.
6. Event date, time, lunch and venue are still in the Save the Date section.
7. Live poll settings are retained in poll-config.js. Test from a web-hosted URL if local file restrictions interfere.
8. No GitHub files have been changed.

Browsers require a user interaction for audible music; tapping the envelope provides it.
